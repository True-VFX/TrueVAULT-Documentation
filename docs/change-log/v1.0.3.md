# v1.0.3

## New
- FASTscatter for asset placement.
- Multi-place functionality for the asset import operator.
- Align with surface normal option when scattering.
- Enhanced status bar updates during asset import.
- Viewport hint when holding Shift for multi-place during import.
- Toggle to ignore instances when scattering.

## Improvements
- Asset import: improved object socket assignment logic and heuristics for the FASTscatter node group.
- Asset placement: option to ignore instances when placing assets.

## Fixes
- Ensure objects are always placed under the mouse during placement.
- Fixed using the wrong node group when scattering a second time.
