# v1.2

## New
- Blender 5.1 support (TrueVAULT now requires Blender 5.1 or newer).
- Preferences: new operator to reload cached asset store data.

## Improvements
- Sign up and password reset now open in your web browser (with captcha) instead of inside Blender.

## Fixes
- Sign up link pointed to the wrong URL.
