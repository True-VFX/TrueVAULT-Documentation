# v1.1

## New
- VDB assets
  - Add VDB as an asset subtype in browse filters and UI icons.
  - Support VDB import with volume placement and robust error handling.
  - Thumbnails support VDB subtype visuals.
- Background downloads
  - Background download with clear progress tracking for download and extraction.
  - Shows currently downloading items in Preferences > Advanced.
- Auto-download on unlock
  - New auto-download settings per type: Textures, Objects, VDBs, Height Maps.
  - Max size preference (0 = unlimited) respected during auto-downloads.
  - Option to Download All Quality Levels for owned assets with updated Preferences UI.
- Import & placement
  - Unpacking progress shown in the Asset Import UI.
  - Multi-place randomization options (random scale, random Z rotation).
  - Option to import singular object assets into their own collection.
- Materials
  - TruePBR: added map toggles (Gloss, Reflection, Dx map) for ST assets.
- UI & UX
  - Caps Lock detection and alert in password fields.

## Improvements
- Asset extraction
  - Enhanced progress reporting for extraction steps.
  - Parallel extraction to speed up installs.
  - Retry logic to handle transient extraction failures.
- Browsing & visuals
  - Enable filtering specifically by VDB subtype.
  - Better display of 2D icons when placement location is off-screen.

## Fixes
- Auto-download: ensure max size set to 0 still permits downloads as intended.
- Thumbnails: include VDB subtype so previews render correctly.
