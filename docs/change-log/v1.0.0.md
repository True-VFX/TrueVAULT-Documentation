# v1.0.0

## New
- Asset browser with search, sort, filters, categories, and tags.
- Product details with gallery, tags, and license view.
- Preference panels for browser settings and product preferences.
- Import support for Textures and Height Maps with ready-to-use .blend setups.
- Download assets while picking the placement location.
- View and manage add-on licenses in the Extensions panel; license info operator.
- Superhive account linking flow with status checks and clear reporting.
- Authentication UI with password requirements and helpful validation.
- Preferences header icons and quick links (including a Tutorials icon).
- Page navigation improvements and a products-per-page preference.
