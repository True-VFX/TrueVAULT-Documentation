# v1.0.1

## New
- Preferences: added a Reinstall Assets operator.

## Improvements
- Added user authentication checks for asset reinstallation with minor Preferences UI refinements.
- Import: only creates the asset directory structure when actually importing; improved "is installed" checks.

## Fixes
- Owned assets library no longer displays unowned assets.
