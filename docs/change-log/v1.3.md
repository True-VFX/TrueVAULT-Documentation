# v1.3

Covers v1.3.0 and v1.3.1.

## New
- Presets
  - Browse, view details for, and download TrueVAULT presets.
  - Purchase missing assets a preset depends on directly from the preset dialog.
  - Cached presets load at startup; only presets for assets you own or need are shown.
- True Terrain integration
  - TrueVAULT assets and presets can be used from inside True Terrain 5.2.
  - Purchased assets and their import data sync to True Terrain in one request.
  - Download Only mode: download an asset without placing it in the scene.

## Fixes
- Error after purchasing preset assets (`_timer` was None).
- Asset metadata and categories are now stored correctly.

## v1.3.1
- Fix: "Forgot password" link opened the wrong page.
